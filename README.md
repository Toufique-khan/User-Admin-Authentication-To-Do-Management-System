# 🔐 User Admin Authentication & To-Do Management System

A fully responsive web application built using **HTML, CSS, and JavaScript** with complete **Admin Panel + User Authentication + To-Do List Management** functionality using **Local Storage**.

This project was created to practice frontend development, UI responsiveness, authentication flow, state management, and local storage handling without using any backend or database.

---

# ✨ Features

## 👤 User Side
- ✅ User Registration System
- ✅ Login Authentication
- ✅ Access Control Based on Admin Approval
- ✅ Fully Functional To-Do List
- ✅ Add, Edit & Delete Tasks
- ✅ Task Progress Bar
- ✅ Light Mode & Dark Mode
- ✅ Fully Responsive UI

## 🛡️ Admin Side
- ✅ Admin Dashboard
- ✅ View All Registered Users
- ✅ Accept User Requests
- ✅ Block Users Anytime
- ✅ Reject User Requests
- ✅ Control User Login Access
- ✅ User Status Management
- ✅ Fully Responsive Admin Panel
